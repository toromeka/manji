# 漫字（まんじ）プレーヤー

小説・漫画・サウンドドラマのあいだにある、自動再生の映像メディアです。

公開サイト: https://toromeka.github.io/manji/

## フォルダ

- `docs/MANJI_AI_GUIDE.md` — `.manji` ファイルを書くための AI 向けオーサリングガイド
- `docs/` — スキーマと解説
- `samples/` — サンプル作品（同梱作は `samples/builtin/`）
- `tools/pack_manji.py` — `.manji` を `.manjiz` に固める・検査するツール
- `manji_kit.zip` — 配布用キット

「坊っちゃん」の本文は夏目漱石（青空文庫）によります。
「耳無芳一の話」は小泉八雲、戸川明三訳（青空文庫）によります。
「朝ごはん裁判」はオリジナル漫才です。
