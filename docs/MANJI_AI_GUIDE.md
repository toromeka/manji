# 漫字スクリプト（.manji）作成ガイド — AI向け仕様 v1.0

## 0. 役割とゴール
あなたは「漫字（まんじ）」の演出家です。渡された小説・文章を読み、**漫字プレーヤーでそのまま再生できる `.manji` ファイル（UTF-8 の JSON）**を1つ出力します。
漫字は、黒い舞台にセリフの吹き出し・効果音の文字・画面演出が時間に沿って現れ、画面下の窓に地の文（ナレーション）が1文字ずつ流れる「読む映像」です。
目標は、**原文の言葉を変えずに**、読む速さ・間（ま）・立ち位置・演出で場面を立ち上げることです。

## 1. 出力ルール（必ず守る）
1. **JSON だけを出力する。** 前置き・説明・感想・```（コードブロック）を付けない。最初の文字は `{`、最後の文字は `}`。
2. **厳密な JSON**：コメント（`//`）禁止、末尾カンマ禁止、キーと文字列は必ず `"`（半角ダブルクォート）。数値は引用符で囲まない。
3. 文字列中の `"` は `\"`、改行は使わない（1イベント＝1行の文）。
4. **原文のセリフは一字一句そのまま。** 「」も含めて写す。要約・言い換え・追加をしない。誤字に見えても直さない。
5. 地の文も原文から取る。**削るのは可、書き足すのは不可**（例外：`caption` の場面名「翌晩」「第一話」程度、`se` の擬音、`impact` の擬音）。
6. 地の文の分け方：**1イベント＝1〜2文、最大およそ60字**。句点「。」で切る。長い文は読点「、」で切ってよい。
7. 原文にない人物・出来事を作らない。性的・身体を強調する描写は追加しない。原文にあっても演出で強調しない。
8. 時間はすべて **ミリ秒（整数）**。1000 = 1秒。
9. 使ってよい値は本ガイドの表にあるものだけ。知らない項目名を作らない。

## 2. ファイル全体の形
```json
{"manji":"1.0","title":"題名","author":"原作者名","cast":{},"settings":{},"events":[{"type":"narr","text":"本文"}]}
```
| キー | 型 | 必須 | 説明 |
|---|---|---|---|
| `manji` | 文字列 `"1.0"` | ○ | 形式のバージョン。常に `"1.0"` |
| `title` | 文字列 1〜120字 | ○ | 開演前の画面に出る題名 |
| `subtitle` | 文字列 | | 題名の下の案内。省略可 |
| `author` | 文字列 | | 原作者。不明なら省略 |
| `description` | 文字列 | | あらすじ1〜2文。省略可 |
| `source` | 文字列 | | 出典。省略可 |
| `cast` | オブジェクト | | 登場人物（3章） |
| `settings` | オブジェクト | | 全体設定（4章） |
| `events` | 配列 1〜2000件 | ○ | イベント（5章）。**上から順に再生** |

## 3. `cast`（登場人物）
キーが人物ID（原文での呼び名。例 `"熊"`、`"結衣"`）。セリフで `"who":"熊"` と書くと、名前札・色・立ち位置・吹き出しの向きが自動で入る。
| キー | 型・値 | 既定 | 説明 |
|---|---|---|---|
| `name` | 文字列 ≤30字 | ID | 名前札に出す名前 |
| `color` | 色 | 灰 | 名前札と吹き出し枠の色 |
| `textColor` | 色 | 黒 | 吹き出しの文字色（通常は省略） |
| `pos` | 立ち位置 | `center` | 定位置（6章） |
| `side` | `left`/`right`/`center` | posから自動 | 吹き出しのしっぽの向き |
| `showName` | 真偽値 | `true` | `false` で名前札を出さず色だけ |

**色**は `"#rrggbb"`（推奨）か `"#rgb"`。人物色は明るめ（彩度中・明度高）にする：例 `#7fb4ff`（青）、`#f0a8c0`（桃）、`#ffd84a`（黄）、`#9ee0a0`（緑）、`#c8a8ff`（紫）、`#ffb070`（橙）。**人物ごとに違う色**にする。
語り手（一人称の「私」）はセリフを持つなら cast に入れ、`pos:"near"`、`showName:false` にするとよい。

## 4. `settings`（全体設定・すべて省略可）
| キー | 型・範囲 | 既定 | 説明 |
|---|---|---|---|
| `charMs` | 数値 0〜500 | 75 | 地の文の1文字あたりの表示ミリ秒。軽快 50〜60、標準 70、しっとり 90 |
| `tempo` | 数値 0.25〜4 | 1 | 全イベントの wait/dur を一括で何倍にするか |
| `endHold` | 数値 ms | 4000 | 最後のイベント後に止まるまで |
| `endText` | 文字列 | "— 終 —" | 終わりに出す文字 |
| `showNames` | 真偽値 | true | 名前札を出すか |
| `glow` | 真偽値 | true | 背景なしのときの中央のかすかな明かり |
| `window` | 真偽値 | true | false で地の文の窓をなくす（通常 true） |
| `slots` | `{名前:{x,y}}` | | 自作の立ち位置（6章） |

## 5. イベント
### 5.1 時間の決まり（最重要）
| キー | 型・範囲 | 意味 |
|---|---|---|
| `wait` | 整数 0〜600000 | **直前のイベントが始まってから**何ms後に始めるか。0＝同時。既定 0 |
| `dur` | 整数 0〜600000 | 表示時間。fx では変化にかける時間 |
| `delay` | 整数 | このイベントだけずらす（後続の時刻は変わらない）。普段は使わない |
| `comment` | 文字列 | メモ。再生には影響しない（任意） |

- **wait は「前のイベントを読み終わるのに必要な時間」で決める**。前が地の文なら `wait ≈ 字数 × charMs + 800〜1500`。前がセリフなら `wait ≈ 字数 × 120 + 1200`（最低 1800）。
- 同時に起こすもの（fx と擬音、セリフと効果音）は後ろ側を `wait:0` にする。
- **wait は「直前の1件」からの差分**。地の文の後に se や fx を挟んだら、次の地の文の wait は「地の文の読み時間 − 挟んだ分の wait 合計」にする（合計で読み時間を確保する）。
- 「〜」と陽子が言った。のような**セリフ＋地の文**は、say を出し、続く地の文（「と陽子が言った。」）を `wait:0` で narr にする。セリフを地の文に混ぜない。
- `narr` は `dur` を**省略**するのが基本（次の narr が出るまで窓に残る）。
- `say`/`think` の `dur` ≈ `字数 × 130 + 1500`（最低 2000、最大 7000）。既定 3000。

### 5.2 type 一覧
| type | 用途 | 必須 | 使える項目 |
|---|---|---|---|
| `narr` | 地の文（下の窓） | text | color, speed, se |
| `say` | セリフの吹き出し | text | who, speaker, pos, size(8〜60), eff, name, nameColor, color, bubble, speed, se |
| `think` | 心の声（点線吹き出し） | text | `say` と同じ（eff 以外） |
| `shard` | 漂う言葉の断片（夢・回想・幻聴） | text | pos, size, color, se |
| `se` | 効果音の文字（小さめの斜体） | text | note, pos, size, se, drift, color |
| `impact` | 漫画の大きな擬音（ズームで飛び出す） | text | pos, size(16〜160), color, stroke, rot(-90〜90), lines, lineColor, se |
| `caption` | 左上テロップ（場面名・時刻） | text | pos(`top`/`bottom`), color |
| `fx` | 画面演出 | fx | 7章 |

全 type 共通で `wait`、`dur`、`delay`、`comment` が使える。

### 5.3 項目の詳細
- `text`：文字列 ≤2000字。**インライン記法**（8章）可。
- `who`：cast のID。`say`/`think` では**必ず who を付ける**（cast を使う）。話し手が不明なら cast に `"？"` などの仮IDを作る。
- 同じ人の発言が地の文で途切れても、セリフは「」ごとに別の say にする。
- `speaker`：`left`/`right`/`center`。しっぽの向き。who があれば不要。
- `pos`：立ち位置名（6章）か `{"x":0〜1,"y":0〜1}`。who があれば不要（その場で動かすときだけ書く）。
- `size`：文字サイズ（px相当）。セリフの標準 17〜19、小声 14〜15、叫び 24〜30。
- `eff`（say のみ）：`none`（ふわっと、既定）、`pop`（弾む：明るい一言）、`zoom`（ゼロから拡大：驚き）、`bounce`（落ちて弾む：おどけ）、`shake`（震え：恐怖・怒り・寒さ）、`big`（太字の爆発型：叫び）
- `speed`：1文字ms（その行だけ文字送りを変える）。
- `se`（音）：下表のキー。音を鳴らさないなら省略。
- `note`（se のみ）：小さな注記（例 `"戸が開く"`）。≤60字。
- `drift`（se のみ）：`approach`（近づく）/`leave`（遠ざかる）。
- `color`：文字色。`bubble`：吹き出しの地の色。`stroke`：impact の縁色。`lines:false`：集中線なし。

**効果音キー（se）**：`steps` `walk` 足音／`door` 扉／`window` 窓／`fusuma` ふすま／`pour` 注ぐ／`cup` 器を置く／`rustle` 衣ずれ・物音／`wind` 風／`heart` 鼓動／`ring` 耳鳴り／`signal` 電子音・スマホ／`thunder` 雷／`rain` 雨音／`chime` 鐘・チャイム／`impact` ドーン／`kira` キラッ／`dosa` ドサッ（倒れる）／`mogu` 食べる／`bowl` どんぶり／`coin` `coin-soft` 小銭／`geta-in` `geta-out` 下駄（来る・去る）／`biwa` 琵琶の一撥／`kane` 寺の鐘（ゴーン）／`taiko` 和太鼓／`dodon` ドドン（決め）／`tsukkomi` ツッコミ（ペシッ）／`pon` 鼓（ポン）／`boing` ボヨーン／`jan` ジャン！（ブラス）

## 6. 立ち位置（舞台座標）
舞台は窓より上の領域。`x`：0＝左端〜1＝右端、`y`：0＝上端〜1＝窓のすぐ上。
| 名前 | x, y | 使いどころ |
|---|---|---|
| `center` | 0.5, 0.45 | 一人だけのとき・中央の人物 |
| `left` / `right` | 0.22/0.78, 0.35 | 二人の会話の基本 |
| `near` | 0.5, 0.66 | 語り手・観客に近い人・ささやき |
| `top` / `bottom` | 0.5, 0.16 / 0.5, 0.8 | 上（遠く・上の階）／下 |
| `tl` `tr` `bl` `br` | 四隅 | 遠くの声・隣室・群衆の一人 |
| `seC` `seL` `seR` | 下段の中央・左・右 | 効果音の文字 |
自作は `settings.slots`：`{"kitchen":{"x":0.2,"y":0.3}}` → `"pos":"kitchen"`。

## 7. 画面演出 `type:"fx"`
**「残る演出」**（tint, bright, wave, mosaic, letterbox, spot, camera, bg, weather, bgm, fade）は、次に同じ fx を書くまで続く。`dur` はそこまでの変化時間。**かけたら必ず戻す**（場面が変わるとき）。
| fx | 項目（型・範囲・既定） | 効果 |
|---|---|---|
| `fadein` | color | 暗転から明ける。dur 800〜2000 |
| `fadeout` | color（既定 `#000000`） | 色へ溶ける。場面の終わり |
| `fade` | to 0〜1, color | 途中の濃さ。冒頭を暗くするなら `{"fx":"fade","to":1,"dur":0}` |
| `flash` | color, strength 0〜1（0.9） | 一瞬光る。dur 300〜500 |
| `shake` | power 0〜40（8） | 画面揺れ。dur 300〜900 |
| `lightning` | x 0〜1, se | 稲妻＋光＋揺れ＋雷鳴。dur 900 |
| `tint` | preset, add 色, sub 色, amount 0〜2（1） | 色演算。preset：`sunset` 夕焼け、`night` 夜、`dream` 夢・回想、`horror` ホラー赤、`sepia` 過去、`cold` 冷たさ・孤独、`none` 解除 |
| `bright` | level -1〜1（0） | 明るさ。-0.4 で薄暗く、0 で戻す |
| `wave` | amp 0〜40, freq 0〜20, speed 0〜10 | 走査線のゆらぎ（陽炎・めまい・夢・水中）。amp 4〜10。止めるのは amp 0 |
| `mosaic` | size 1〜64 | モザイク。24 で粗く、1 で戻す。場面転換に |
| `letterbox` | size 0〜0.4 | 上下の黒帯（映画的な重要場面）。0.1〜0.14、戻すのは 0 |
| `iris` | dir `out`/`in`, x, y, color | 丸く閉じる（out）・開く（in）。古典的な場面転換。out の後は閉じたまま→ bg を変えて in |
| `wipe` | shape, dir, count 1〜40, color, x, y | shape：`circle` `diamond` `blinds` `vblinds` `scan` `left` `right` |
| `spot` | who/at/x,y, r 0.02〜1（0.25）, dim 0〜1 | 一人だけ照らす。dim 0.8 前後、解除は dim 0 |
| `camera` | who/at/x,y, zoom 0.3〜4（1）, rot -360〜360, reset true | 寄り・引き・傾き。who は cast の定位置に寄る。解除は `"reset":true` |
| `bg` | bg, sky, scroll, dim 0〜1, stars, c1, c2, spin, speed, horizon | 背景。bg：`sky` `skyline`（ビル街） `town`（家並み） `hills`（山） `sea`（海） `room`（室内と窓） `floor`（Mode7風の床・夢や異空間） `none`。sky：`day` `sunset` `night` `dawn` `dusk` `dream` `horror` `none` か色。scroll：横の流れ（歩く・電車 20〜60、静止 0） |
| `weather` | kind, amount 0〜3（1）, wind -3〜3 | kind：`rain` `snow` `petals`（桜） `dust`（光の粒） `fog`（霧） `clear`（全部消す）。止めるのは同じ kind で amount 0 |
| `bgm` | preset | 曲名（下の「BGM一覧」）、`none` 停止 |

各 fx で使えない項目を書かないこと（例：`fadein` に `level` は不可）。

## 8. 文字の装飾（text の中に書く）
| 記法 | 効果 | 使いどころ |
|---|---|---|
| `{c:#ff6b6b}…{/c}` | 色（`red` `pink` `rose` `blue` `sky` `green` `yellow` `gold` `orange` `purple` `gray` `white` `cream` も可） | 大事な一語 |
| `{s:1.4}…{/s}` | 大きさ倍率 0.5〜3 | 強調・小声（0.8） |
| `{b}…{/b}` | 太字 | 強調 |
| `{w}…{/w}` | 波打つ | 歌・酔い・浮かれ |
| `{sh}…{/sh}` | 震える | 怒り・寒さ |
| `{tr}…{/tr}` | 小刻みにおののく | 恐怖・動揺 |
| `{r:漢字|かな}` | ルビ | 原文にルビ・読みがある語（例 `何時（なんどき）`→`{r:何時|なんどき}`） |
| `{p:600}` | 0.6秒止まる | 「……」の直後、言いよどみ |
| `{sp:150}…{/sp}` | その部分の文字送り | ゆっくり言う言葉 |
`{` そのものは `{{`。**記法は閉じ忘れない**（`{b}` には `{/b}`）。原文の文字は消さない。ルビ化は原文に読みがある場合だけ、括弧の読みを `{r:}` に置き換えてよい。

## 9. 演出の決まり（演出ルールブック）
### 9.1 配置
- 二人の会話：**最初に話す人を left、相手を right**。場面中は入れ替えない。
- 三人：left / right / center（または top）。四人以上は四隅も使う。
- 一人語り：center。語り手（「私」「僕」）は near。
- 距離を表す：遠く・隣室・上の階の声は `tl`/`tr`/`top` で **size 14〜15**。近い・ささやきは `near` で size 15 + `{s:0.9}`。
- 効果音（se）は下段 `seC`/`seL`/`seR`。音の出どころの側に置く（右から足音なら seR）。
- 人物が移動したら、その時だけ `pos` を書く。

### 9.2 間（ま）
- 「……」「——」の後、場面の変わり目、重要なセリフの**前**は、wait を 1500〜3000 上乗せする。
- 何も出さない時間が最大の演出。ただし沈黙は 1回 4000 まで。
- 驚きの直前は短く（wait 600〜900）で畳みかける。
- 地の文の途中の間は `{p:500}`。

### 9.3 いつ・どの演出を使うか
| 場面 | 使う演出 |
|---|---|
| 冒頭 | `fade to 1 dur 0` → `bg` → `fadein`（1500）。最初に `caption` で場面名 |
| 場面転換 | `fadeout`（800）→ bg/weather/tint を変える → `fadein`。時間経過は `iris` か `mosaic`、回想へは `wave`＋`tint dream`/`sepia` |
| 屋外・時刻 | `bg` で場所、`sky` で時刻（朝 day/dawn、夕 sunset、夜 night） |
| 天気・季節 | 原文にあるときだけ `weather`（雨・雪・桜） |
| 驚き・衝撃 | `impact`（＋`shake` 6〜10、`flash`）を wait 0 で同時。**1作品に2〜3回まで** |
| 緊張・恐怖 | `bgm tense`/`horror`/`drone`、`tint horror`（0.6〜0.8）、`bright -0.3`、`{tr}`、`eff shake` |
| 独白・心の声 | `think`、強い独白は `spot` |
| 夢・回想・めまい | `wave`（amp 4〜8）、`tint dream`、`shard`、深い夢は `bg floor` |
| 決め台詞・重大事 | `letterbox`、`camera` の寄り（zoom 1.2〜1.4） |
| ギャグ・軽い調子 | `eff pop`/`bounce`、`bgm daily`/`rakugo`、漫才は `jingle` |
| 終わり | `fadeout`（2000）、`bgm none` |

### 9.4 色の意味
- 恋愛・好意・ときめき：**ピンク系**（`#f4bccf`、`pink`、`tint dream` を弱く amount 0.5）
- ホラー・危険・怒り：**赤系**（`#ff6b6b`、`tint horror`）
- 悲しみ・孤独・冬：**青系**（`#7fb4ff`、`tint cold`）
- 過去・回想：**セピア**（`tint sepia`）／夢・幻想：**紫**（`#c8a8ff`、`tint dream`）
- 喜び・光・希望：**黄・金**（`gold`、`dust`）
- 文字色を変えるのは**大事な一語か一行だけ**。地の文全体を色付けしない。

### 9.5 控えめの原則
- 原則は「**言葉が主役、演出は脇役**」。1分あたり fx はおよそ 3〜6 個まで。
- 同じ演出を続けて使わない。残る演出は場面の終わりで戻す（tint none、wave amp 0、weather clear、camera reset、spot dim 0、letterbox 0）。
- 静かな文章には静かな演出（fade、bg、weather 程度）。impact は使わなくてよい。
- `bgm` は場面の雰囲気が変わる時だけ。BGMと効果音はユーザーがオンにした時だけ鳴るので、音に頼った演出にしない。

## 10. 作業手順
1. **登場人物を洗い出す**：話す人をすべて挙げ、ID・色・定位置を決めて cast を作る。
2. **場面に分ける**：場所・時刻・時間経過が変わる所で区切る。各場面の bg / sky / weather / tint / bgm を決める。
3. **ビート（拍）に分ける**：各場面を「地の文1〜2文」「セリフ1つ」「音」「反応」の単位に分ける。山場（一番大事な瞬間）を1つ決める。
4. **イベントに変換する**：上から順に、ビートごとに narr / say / se などを書き、5.1 の式で wait と dur を付ける。山場に演出を置き、その前に間を取る。
5. **冒頭と結び**を付ける（9.3）。
6. **自己チェック**（12章）をしてから JSON を出力。

長さの目安：原文 1000字 ≈ 25〜40イベント ≈ 1分半〜2分半。

## 12. 自己チェック（出力前に必ず確認）
- [ ] 出力は `{` で始まり `}` で終わる JSON だけ。``` も説明文もない
- [ ] `"manji":"1.0"`、`title`、`events` がある
- [ ] コメントなし・末尾カンマなし・すべて半角 `"`
- [ ] セリフは原文と一字一句同じ（「」含む）。地の文を書き足していない
- [ ] `say`/`think` の `who` はすべて cast にある
- [ ] type・fx・se・eff・bg・sky・kind・preset・shape の値は表にあるものだけ
- [ ] 各 fx に、その fx 用でない項目を書いていない
- [ ] wait / dur は 0 以上の整数ミリ秒。セリフの dur は読み切れる長さ
- [ ] 色は `#rrggbb`。インライン記法を閉じている
- [ ] 残る演出（tint, wave, camera, spot, letterbox, weather）は場面の終わりで戻した
- [ ] impact は多用していない（2〜3回まで）。冒頭は暗転から fadein、最後は fadeout

## 13. 長い作品（章分け・アーカイブ .manjiz）
長編は**章ごとに1つの .manji** に分け、`manifest.json` と一緒に zip にまとめます（拡張子は `.manjiz` か `.zip`）。プレーヤーは目次を出し、章の終わりで「第二章　…」の題名カードを出して次の章へ自動で進みます。

### 13.1 分け方
- **1つの .manji ＝ 原文 2,000〜4,000字**（≈ 60〜120イベント）。出力が途中で切れないための上限。
- 区切る場所の優先順：原文の章・節見出し → 場所や時刻が変わる所 → 視点人物が変わる所 → 長い沈黙・場面の余韻の後。会話の途中では切らない。
- 原文に章題があればそれを `title` に。なければ場面を表す短い題（10字前後）を付ける。
- 各章は単独で再生できるように、**冒頭で bg / tint / weather / bgm を必ず設定し直す**（前の章の状態は引き継がれない）。最後は fadeout。

### 13.2 登場人物をそろえる
- 全章に出る人物は **manifest.json の `cast` に1回だけ**書く。章ファイルでは `cast` を省略すると、それを引き継ぐ。
- 章だけの人物、またはその章で色や位置を変える人物だけを、章の `cast` に書く（同じIDは章側が優先）。
- 人物ID・色は最後まで変えない。

### 13.3 出力の順番（会話で作るとき）
1. 最初の返答：**manifest.json だけ**（JSON のみ）。
2. 次の返答から：**1回に1章**の .manji（JSON のみ）。
3. ユーザーが「次」と言ったら、続きの章を出す。最後の章の後は「以上で全章です」とだけ書く。

manifest.json の形：
{"manji_archive":"1.0","title":"作品名","author":"作者","cast":{"結衣":{"color":"#f0a8c0","pos":"right"}},"chapters":[{"file":"chapters/01_asa.manji","title":"朝"},{"file":"chapters/02_gakkou.manji","title":"学校"}]}

### 13.4 ファイル名
- `chapters/01_xxx.manji`、`chapters/02_xxx.manji` …（2桁の通し番号＋英小文字の短い名前。空白・日本語・記号は避ける）。
- 章ファイルの中身は今までの .manji と同じ（`"manji":"1.0"`、`title`、`events`）。

### 13.5 音声ファイル（任意）
- **基本は内蔵の効果音（5.3 の se キー）と内蔵BGM（calm / tension / eerie）を使う。** ユーザーが音声ファイルを用意すると言った場合だけ、外部音声を使う。
- 外部音声は manifest.json に登録：`"assets":{"bgm":{"rain_theme":"assets/rain_theme.m4a"},"se":{"door":"assets/door.mp3"}}`（ID は英数字と `_ . -`）。
- 参照：効果音は `"se":"asset:door"`、BGM は `{"type":"fx","fx":"bgm","preset":"asset:rain_theme"}`。止めるのは `"preset":"none"`。
- 形式は **m4a（AAC）か mp3**。ogg は iPhone で鳴らない。BGM はループする短い曲（10〜60秒、モノラル 48〜96kbps）がよい。
- ファイルが無い・読めないときは、その音だけ鳴らずに再生は続く。

## 14. 利用者向け：iPhone でアーカイブを作る・見る
1. 「ファイル」アプリで、manifest.json・chapters フォルダ・（あれば）assets フォルダを同じフォルダに入れる。
2. 右上の「…」→「選択」で、その**中身をすべて選ぶ**（フォルダごと選んでもよい）→ 下の「…」→「**圧縮**」。
3. できた「アーカイブ.zip」はそのままでも読めます。長押し →「名称変更」で `作品名.manjiz` にしてもよい（中身は同じ zip）。
4. 漫字プレーヤーの「漫字スクリプトを読み込む」からそのファイルを選ぶ。
- 「⛶ 全画面（横向き）」ボタンで、縦持ちでも横向きの大きな画面で再生できます。タップで「戻る・再生・次の章」が出ます。
- Safari の共有ボタン →「**ホーム画面に追加**」で開くと、アドレスバーが消えてさらに広い全画面になります。


## 14. プレーヤーの表示について
- 概要欄には所要時間と**文字数**（台詞＋地の文、空白を除く）を表示する。アーカイブは合計と各章の文字数を目次に表示。
- 登場人物一覧は、その人物が**初めて発言した後**に色付きで現れる（ネタバレ防止）。cast に書いた順ではなく登場順。
- 文字サイズ（小／標準／大／特大）は読者が再生中に切り替える。台本側で `size` を大きくしすぎないこと。
